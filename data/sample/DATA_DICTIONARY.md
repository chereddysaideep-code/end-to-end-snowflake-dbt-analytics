# Sample Dataset Data Dictionary

All records are synthetic and created for portfolio demonstration.

- `customers.csv`: customer_id, customer_name, country, signup_date, customer_segment
- `products.csv`: product_id, product_name, category, price
- `orders.csv`: order_id, customer_id, order_date, status
- `order_items.csv`: order_id, product_id, quantity, unit_price
